# Grizzy AI · Технический писатель / контент-мейкер — тестовое задание

Задание «Документация для раннего доступа». По внутренним заметкам разработчиков, техническому changelog и обращениям в поддержку вы пишете для инди-разработчиков «Быстрый старт», FAQ, примечания к выпуску и текст лендинга с листом ожидания, а расхождения в материалах выносите в отдельный список вопросов.

Постановка задачи — в документе `Тестовое_задание_Tech_Writer.pdf`.

## Как сдать

Задание — в `Тестовое_задание_Tech_Writer.pdf`, материалы — в этом репозитории: нажмите «Use this template», чтобы создать свою копию. Ссылку на свой публичный репозиторий с решением пришлите на gpetrov@hse.ru. Вопросы — туда же.

## Состав пакета

| Путь | Что это |
|---|---|
| `Тестовое_задание_Tech_Writer.pdf` | задание: задача, входные данные, что сделать, как сдать |
| `materials/dev_notes.md` | внутренние заметки разработчиков о плагине: установка, вход, кредиты, инструменты агента, лимиты, настройки, политика доступа к файлам, известные проблемы |
| `materials/changelog.md` | технический changelog версий 0.8.0–0.9.1 |
| `materials/tickets.md` | 15 обращений пользователей в поддержку (T-01–T-15) |
| `materials/product_brief.md` | бриф продакт-менеджера: аудитория, что обещаем, ранний доступ, лист ожидания, тон |
| `templates/questions.md` | шаблон списка расхождений, вопросов к разработчикам и покрытия обращений |

## Как начать

```bash
mkdir grizzy-docs && cd grizzy-docs && git init
mkdir docs && cp ../templates/questions.md .
```

Материалы из `materials/` можно положить в репозиторий рядом с решением, но не меняйте их: на них ссылаются ваши выводы в `questions.md`.
