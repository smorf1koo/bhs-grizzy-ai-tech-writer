- feat(billing): служебная сводка запроса для логов теперь на дешёвой модели и за счёт платформы, у юзера не списывается
- fix(plugin): Windows — история чата терялась после перезапуска редактора (#412)
- fix(agent): `get_errors` отдавал старые ошибки после сохранения скрипта (#418)
- fix(policy): глоб `**` не матчил файлы в корне проекта (#421)
- perf(context): экспорт дерева сцены в 3 раза быстрее на сценах > 1000 узлов
- chore(ci): включили матрицу сборки плагина win/mac/linux
- chore(deps): fastapi 0.115 -> 0.118

## 0.9.0 — 2026-10-20

- BREAKING: минимальная версия Godot 4.4 (переехали на godot-cpp 4.4). Сборки под 4.2/4.3 больше не выпускаем, на них плагин не загружается
- feat(auth): вход через OAuth device flow, единый аккаунт Bear Head Studio. Токены в системном хранилище (Keychain / Credential Manager / libsecret). Вход по API-ключу deprecated, работает до 0.10
- feat(billing): общие кредиты экосистемы BHS вместо отдельного баланса Grizzy; старый баланс перенесён 1:1. Перед ходом резервируем оценку на все итерации, списываем по факту, остаток возвращаем. Ошибка сервера или обрыв соединения — резерв возвращается целиком
- feat(billing): цена хода по тарифу фактической модели вместо сырых токенов
- feat(ui): оценка стоимости хода в панели до отправки запроса
- feat(policy): проверка политики в одной точке (исполнитель команд), жёсткий deny-list (`.git/`, `.godot/`, `.env*`, `*.key`, `*.pem`, `addons/grizzy_ai/`) не переопределяется пользовательской политикой
- feat(tools): `delete_file` и перезапись существующего файла в `write_script` — только после подтверждения юзером в панели; перед записью копия в `res://.grizzy/backups/`, хранится 7 дней
- infra: переезд на инфраструктуру BHS, новый адрес `wss://api.grizzy.example.com`; старый `wss://grizzy-api.example.net` отключаем 2026-12-15, версии < 0.9.0 после этого не подключатся
- db: миграции в общую БД, схема `grizzy` (alembic)
- refactor(protocol): описание инструментов отвязано от Godot (задел под Unity/Unreal)
- fix(plugin): краш при закрытии редактора во время хода агента (#377)
